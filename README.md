# Invisiblepalmistry

YH’s portfolio: art, design, research and experiments.

The repository root is the complete static website published by GitHub Pages. Open `index.html` for the workbench, `about.html` for the typewriter, and the collection pages for Research, Playground and Commercial Work. The travel album is in `travel/`.

Shared images, audio, models and browser libraries are stored once and reused by the pages. Collection entry files intentionally share one board implementation. Third-party licence notices remain with the libraries.

Publish the existing `main` branch from `/`. No WordPress server or Reclaim account is needed. Use relative links so the same site works at the GitHub address and a future custom domain.

Keep source media originals, screenshots and ZIP backups outside this repository. GitHub retains commit history; do not add duplicate website folders or full release archives.

Behavioral Ripples retains its archived article design and independently hosted p5.js / Flourish embeds. Commercial films retain their original Xinpianchang embeds. Camera, microphone and audio remain browser-controlled and visitor-initiated.
